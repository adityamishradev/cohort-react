# 📦 localStorage – Complete Notes (Easy Hinglish)

## 🔹 localStorage kya hota hai?
`localStorage` browser ka **built-in storage** hota hai jisme hum **key–value** pair me data store kar sakte hain.

- Data **browser band hone ke baad bhi safe rehta hai**
- Jab tak user manually clear na kare, data delete nahi hota

---

## 🔹 localStorage vs sessionStorage

| Feature | localStorage | sessionStorage |
|------|-------------|----------------|
| Data persist | ✅ Yes | ❌ No |
| Browser close | Data safe | Data delete |
| Capacity | ~5–10 MB | ~5 MB |
| Use case | Login, cart, theme | Temporary data |

---

## 🔹 Important Point
⚠️ `localStorage` **sirf string** store karta hai  
Isliye:
- Object / Array → `JSON.stringify()`
- Read karte time → `JSON.parse()`

---

## 🔹 localStorage Methods

| Method | Description |
|------|-------------|
| setItem() | Data save |
| getItem() | Data read |
| removeItem() | Single key delete |
| clear() | All data delete |
| key() | Key name get |
