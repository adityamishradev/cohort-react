# 📦 localStorage – Complete Notes (Easy Hinglish)

## 🔹 localStorage kya hota hai?
`localStorage` browser ka **built-in storage** hota hai jisme hum **key–value** pair ke form me data store kar sakte hain.  
✔ Browser band hone ke baad bhi data safe rehta hai  
✔ Jab tak manually clear na ho, data delete nahi hota

---

## 🔹 localStorage vs sessionStorage

| Feature | localStorage | sessionStorage |
|------|-------------|----------------|
| Data persist | ✅ Yes | ❌ No |
| Browser close | Safe | Delete |
| Capacity | ~5–10 MB | ~5 MB |
| Use case | Login, cart, theme | Temporary data |

---

## 🔹 Important Rule
⚠️ `localStorage` **sirf string store karta hai**

- Object / Array → `JSON.stringify()`
- Read karte time → `JSON.parse()`

---

## 🔹 localStorage Methods

| Method | Use |
|------|----|
| setItem() | Data save |
| getItem() | Data read |
| removeItem() | One key delete |
| clear() | All data delete |

---

## 🔹 Basic Examples

### 1️⃣ Data Save (setItem)
```
localStorage.setItem("name", "Aditya");
✔ Browser me store ho jayega
```
### 🔹 2️⃣ Data Get (getItem)
```
let username = localStorage.getItem("name");
console.log(username);

🖥 Output:Aditya
```
### 🔹 3️⃣ Data Delete (removeItem)
```
localStorage.removeItem("name");
```
### 🔹 4️⃣ Sab Clear (clear)

```
localStorage.clear();
⚠️ Pure localStorage clean ho jayega
```
### 🔹 5️⃣ Object Store Example (MOST IMPORTANT)
```
❌ Wrong way
localStorage.setItem("user", { name: "Amit" });

✅ Correct way
const user = {
  name: "Amit",
  email: "amit@gmail.com"
};

localStorage.setItem("user", JSON.stringify(user));
```
---
### 🔹 Object Read karna
```
const storedUser = JSON.parse(localStorage.getItem("user"));
console.log(storedUser.name);

🖥 Output:Amit
```
### 🔹 6️⃣ Array Store Example
```
const skills = ["HTML", "CSS", "JS"];

localStorage.setItem("skills", JSON.stringify(skills));
Read Array


const data = JSON.parse(localStorage.getItem("skills"));
console.log(data[1]);

🖥 Output: CSS
```
# 🛠️ Mini Project: To-Do List using localStorage

### 🔹 HTML
```
<input id="task" placeholder="Enter task" />
<button onclick="addTask()">Add</button>

<ul id="list"></ul>
```
---
### 🔹 JavaScript
```
let tasks = JSON.parse(localStorage.getItem("tasks")) || [];

function addTask() {
  const input = document.getElementById("task");
  tasks.push(input.value);

  localStorage.setItem("tasks", JSON.stringify(tasks));
  input.value = "";
  showTasks();
}

function showTasks() {
  const list = document.getElementById("list");
  list.innerHTML = "";

  tasks.forEach((task) => {
    const li = document.createElement("li");
    li.innerText = task;
    list.appendChild(li);
  });
}

showTasks();
```

# 📦 React localStorage – All Operations (Single Page Notes)

## 🔹 Example Data
Hum ek **user object** store karenge:

```js
{
  name: "Aditya",
  email: "aditya@gmail.com",
  role: "student"
}
```
---
```
import React, { useState, useEffect } from "react";

const LocalStorageExample = () => {
  const userData = {
    name: "Aditya",
    email: "aditya@gmail.com",
    role: "student"
  };

  const [output, setOutput] = useState(null);

  // 🔹 READ (page load par)
  useEffect(() => {
    const data = localStorage.getItem("user");
    setOutput(data ? JSON.parse(data) : null);
  }, []);

  // 🔹 SET
  const handleSet = () => {
    localStorage.setItem("user", JSON.stringify(userData));
    setOutput(userData);
  };

  // 🔹 GET
  const handleGet = () => {
    const data = localStorage.getItem("user");
    setOutput(data ? JSON.parse(data) : null);
  };

  // 🔹 DELETE (single key)
  const handleDelete = () => {
    localStorage.removeItem("user");
    setOutput(null);
  };

  // 🔹 CLEAR ALL
  const handleClearAll = () => {
    localStorage.clear();
    setOutput(null);
  };

  return (
    <div>
      <h3>React localStorage Example</h3>

      <button onClick={handleSet}>SET DATA</button>
      <button onClick={handleGet}>GET DATA</button>
      <button onClick={handleDelete}>DELETE DATA</button>
      <button onClick={handleClearAll}>CLEAR ALL</button>

      <hr />

      <h4>OUTPUT:</h4>

      {output ? (
        <ul>
          <li>Name: {output.name}</li>
          <li>Email: {output.email}</li>
          <li>Role: {output.role}</li>
        </ul>
      ) : (
        <p>No Data Found</p>
      )}
    </div>
  );
};

export default LocalStorageExample;
```
